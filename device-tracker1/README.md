# 📱 كاشف نوع جهاز الزوار — Device Tracker

موقع تشارك رابطه (مثلاً في تيك توك)، وأي شخص يفتحه من جهازه — يظهر لك **نوع جهازه** في لوحة خاصة بك.

## الملفات

| الملف | وظيفته |
|---|---|
| `server.js` | السيرفر — يستقبل معلومات الزوار ويحللها |
| `public/index.html` | الصفحة التي يفتحها أصدقاؤك |
| `public/admin.html` | لوحتك الخاصة — تشاهد منها كل الزيارات |
| `package.json` | إعدادات المشروع |

## طريقة الحصول على رابط حقيقي (مجانًا — عبر Render)

1. أنشئ حسابًا مجانيًا على [render.com](https://render.com)
2. ارفع هذا المجلد كمستودع GitHub (أو اسحبه مباشرة في Render عبر "New Web Service")
3. في إعدادات الخدمة:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - أضف **Environment Variable** اسمها `ADMIN_PASSWORD` وقيمتها كلمة سر قوية تختارها
4. اضغط Create — وراح يعطيك رابط مثل: `https://your-app.onrender.com`

## الاستخدام

- **الرابط الذي تشاركه في تيك توك:** `https://your-app.onrender.com` — أرسله لصاحبك
- **لوحة المشاهدة الخاصة بك:** `https://your-app.onrender.com/admin.html` — افتحها وأدخل كلمة السر، وشاهد كل من دخل ونوع جهازه (موبايل/تابلت/كمبيوتر + النظام + المتصفح + الشاشة + IP) — تتحدث تلقائيًا كل 10 ثوانٍ

> ⚠️ كلمة السر الافتراضية في `server.js` هي `my-secret-123` — **غيّرها** أو استخدم متغير البيئة `ADMIN_PASSWORD` عند النشر.

## تجربة محلية (تحتاج تثبيت Node.js)

```bash
npm install
npm start
```
ثم افتح `http://localhost:3000` (صفحة الزائر) و `http://localhost:3000/admin.html` (لوحتك).

## ملاحظات

- تيك توك أحيانًا يحظر الروابط الخارجية في التعليقات؛ الأفضل وضعه في **البايو** أو إرساله برسالة.
- تيك توك يفتح الروابط في متصفحه الداخلي، لكن الكشف يشتغل عادي لأن بيانات الجهاز تُرسل بكل الأحوال.
- يُحفظ آخر 500 زيارة فقط.
- استخدم الموقع باحترام — لا تستخدمه لجمع بيانات حساسة أو مضايقة أحد.
